P Policy

Privacy policy

Effective August 28, 2026

Porter keeps the real journal in your browser. The web demo uses a separate sample-data key.

What the extension stores

The extension stores an encrypted vault in browser extension storage. It contains workspace names, task titles, notes, status values, and URLs that you add. Encryption uses AES-256-GCM with a key derived from your passphrase using PBKDF2-SHA-256. The extension keeps the passphrase in browser session storage.

Browser permissions

Porter uses extension storage, the active tab, and optional per-origin permissions. It asks for an origin only when you choose “Use this tab.” It saves the URL you chose. It does not install a page content script.

Exports and sidecar

Encrypted JSON exports are created on your device. Readable Markdown exports are unencrypted and show a warning before creation. The optional sidecar listens only on 127.0.0.1 and writes an encrypted envelope beneath the workspace directory you choose. It rejects ordinary web origins.

Website data

This site includes no analytics, advertising pixels, third-party fonts, or social trackers. Static hosting may retain short-lived security and access logs such as IP address, request path, and user agent.

Deletion and control

Remove the extension to delete its local browser storage, and delete exported files wherever you saved them. To remove a sidecar copy, delete .workspace-history-porter/handoff.json from that workspace. Resetting the demo replaces only its sample data.

Contact

For privacy questions or deletion help, open an issue in the project repository. Because journals never reach us, we cannot recover or delete a journal on your behalf.
