02 How it works

Save the next thing to do

Add a task, a concise note, or a URL you will need when you reopen the workspace.

  1. 01

    Add a task or note

    Create a workspace journal and add the next task or handoff note.

  2. 02

    Bookmark a useful link

    Attach a terminal, pull request, test, or documentation URL after choosing it.

  3. 03

    Import the handoff

    Export encrypted JSON and import it in another browser with the same passphrase.
