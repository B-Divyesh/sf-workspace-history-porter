02 The route

Three stops. No cloud account.

Keep the operational index around the work—not another proprietary copy of the conversation.

  1. 01

    Pack what matters

    Add the next task, a concise handoff note, or the current terminal, PR, test, or docs URL. Page content is never read.

  2. 02

    Seal it locally

    Your passphrase derives an AES key in the browser. The journal stored on disk is ciphertext; the key is not persisted.

  3. 03

    Open the next stop

    Import the encrypted JSON or pull it from the optional workspace sidecar. Merge newer entries without losing local work.
